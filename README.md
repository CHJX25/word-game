# 双阵营猜词：四人互联网联机版

## 本地运行
1. 安装 Node.js 18 或更高版本。
2. 在本目录打开终端：
   npm install
   npm start
3. 浏览器访问 http://localhost:3000

## 同一 Wi-Fi 手机测试
让电脑和手机连接同一 Wi-Fi。查出电脑的局域网 IP（例如 192.168.1.20），手机访问：
http://192.168.1.20:3000

如果无法访问，请确认系统防火墙允许 Node.js/3000 端口。

## 真正互联网联机
把整个项目部署到支持 Node.js + WebSocket 的公网托管服务，并把启动命令设为：
npm start

部署成功后会得到一个 HTTPS 地址。四台手机打开同一地址；第一人创建房间，把 6 位房间号或带 ?room=xxxxxx 的链接分享给另外三人。

## 已实现
- 6 位房间码
- 四个固定角色（红/蓝知晓者、红/蓝猜测者）
- 5×5 不重复词语
- 9/8 阵营分配、7 个无主词、1 个死亡词
- 9 词阵营先手
- 服务端保存秘密答案；猜测者不会收到未翻牌阵营
- 提示词 + 数字
- 猜对继续、猜错换回合、主动结束回合
- 死亡词立即失败、找完己方词立即获胜
- 基础断线刷新重连
- 再来一局

## 生产环境建议
当前房间数据保存在服务器内存中，所以服务器重启会丢失房间。正式长期运营时可增加 Redis/数据库、登录鉴权、房间过期清理、房主权限、限流和更完整的断线恢复。

## v1.1 优化
- 玩家先进入房间，再在大厅选择红/蓝阵营与知晓者/猜测者身份。
- 服务端禁止提示词与任一场上词语完全相同、互相包含，或无声调拼音完全相同。
- 死亡词在知晓者视图中使用黑色+红色双重边框；翻开后显示骷髅、“死亡”字样和高对比警示纹理。
